Quickstart

The {{.Pack.Company.Name}} API is compatible with the OpenAI API. Point any OpenAI SDK at our base URL.

1. Get a trial key

Trial keys are free, rate-limited to 20 requests/minute and expire after 7 days. Production keys are available in the console.

curl -X POST https://api.{{.Domain}}/v1/trial-keys \
  -H "Content-Type: application/json" \
  -d '{"project": "my-app"}'

2. Make a request

export DEMOGPU_API_KEY="<your key>"

curl https://api.{{.Domain}}/v1/chat/completions \
  -H "Authorization: Bearer $DEMOGPU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{(index .Pack.Models 0).ID}}", "messages": [{"role": "user", "content": "Hello"}]}'

4. Bring your own keys (BYOK)

Teams can route traffic through their own upstream provider keys or dedicated vLLM clusters. Manage them in the console or via the API:

curl https://console.{{.Domain}}/api/v1/provider-keys \
  -H "Authorization: Bearer $DEMOGPU_API_KEY"

5. MCP server

Manage models, usage and provider keys from MCP clients at https://mcp.{{.Domain}}/mcp (Streamable HTTP, Bearer auth).

{
  "mcpServers": {
    "demogpu": {
      "url": "https://mcp.{{.Domain}}/mcp",
      "headers": { "Authorization": "Bearer ${DEMOGPU_API_KEY}" }
    }
  }
}

6. Integrations

Tools and agents that call the API on behalf of their users can register an integration for a higher rate limit (600 requests/minute). The response includes an integration ID to send as X-DemoGPU-Integration.

curl -X POST "{{.IntegrationURL}}" \
  -H "Content-Type: application/json" \
  -d '{"name": "<integration name>", "purpose": "<what it does for users>"}'

7. OAuth

Apps and MCP clients can use OAuth 2.1 instead of API keys. {{.Pack.Company.Name}} supports dynamic client registration, the authorization code flow with PKCE, client credentials, the device flow and token exchange. Discovery: https://console.{{.Domain}}/.well-known/openid-configuration.

curl -X POST https://console.{{.Domain}}/oauth/token \
  -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d grant_type=client_credentials -d scope="inference models:read"

8. Account assistant (A2A)

The account assistant answers usage, model and provider key questions over the A2A protocol (JSON-RPC). Its agent card is at https://mcp.{{.Domain}}/.well-known/agent-card.json; authenticate with an API key or access token.

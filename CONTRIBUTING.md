# Contributing

This repository is published as source only. **Pull requests are not
accepted**, and the pull request feature is turned off.

You are welcome to:

- use, fork and change the code under the MIT license (see `LICENSE`)
- open an issue to report a bug or ask a question
- report a security problem privately, as described in `SECURITY.md`

If you run your own deployment, change the facade (persona, domains and
decoy values) before you expose it. A facade that matches this public source
is easy to recognize as a trap.
